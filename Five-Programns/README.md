# Five Programs: Bash Scripting Workshop 🐚

Este proyecto consiste en una serie de 5 scripts de Bash desarrollados para practicar la lógica de programación, el manejo de variables y la interacción con el usuario en entornos Linux.

## 📁 Scripts Incluidos:
1. **questionnaire.sh**: Manejo de entradas y salidas de texto.
2. **countdown.sh**: Uso de bucles (loops) y condicionales.
3. **bingo.sh**: Generación de números aleatorios y lógica de juegos.
4. **fortune.sh**: Creación de un programa interactivo de predicciones.
5. **map.sh**: Procesamiento de datos y estructuras de control.

## 🛠️ Habilidades Aplicadas:
- Automatización de tareas mediante **Bash Scripting**.
- Uso de comandos de terminal como `if`, `while`, `until` y `case`.
- Manejo de permisos de ejecución y variables de entorno.
